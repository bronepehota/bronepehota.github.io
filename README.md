# Бронепехота (Bronepehota)

Веб-помощник для настольной варгеймы «Бронепехота» от компании [Технолог](http://www.tehnolog.ru/).

**Попробуйте демо:** [bronepehota.onrender.com](https://bronepehota.onrender.com/)

## О игре

«Бронепехота» — это настольная варгейма с миниатюрами, где игроки управляют армиями трёх фракций в futuristic setting. Каждая армия состоит из отрядов пехоты и боевых машин, имеющих уникальные характеристики и способности.

### Фракции

- **Полярис** — высокотехнологичная армия с передовым вооружением
- **Протекторат** — мощная и хорошо защищенная фракция
- **Наёмники** — универсальные бойцы с гибкими возможностями

## Возможности приложения

### Конструктор армии

* Фильтрация отрядов по фракции, типу и стоимости
* Поиск по названию
* Добавление отрядов и машин в армию
* Контроль балла очков
* Экспорт и импорт армии в формате JSON

### Игровая сессия

* Управление состоянием армии во время боя
* Отслеживание прочности техники, боезапаса и потерь среди солдат
* Учёт использованных действий каждым отрядом

### Помощник атаки

* Калькулятор попаданий с учётом дистанции
* Калькулятор урона по бронированию цели
* Анимированная бросок кубиков (D6, D12, D20)
* Расчёт ближнего боя

### Редактор армлистов

* Создание собственных отрядов и машин
* Редактирование существующего контента
* Загрузка изображений для отрядов и техники

## Быстрый старт

1. Откройте [bronepehota.onrender.com](https://bronepehota.onrender.com/)
2. Выберите фракцию
3. Нажмите «+» чтобы добавить отряды в вашу армию
4. Переключитесь в режим «В Бой» для управления игровой сессией
5. Используйте вкладку «Атака» для расчёта боя
