# Бронепехота (Bronepehota)

Веб-помощник для настольной варгеймы «Бронепехота» от компании [Технолог](http://www.tehnolog.ru/).

**Попробуйте демо:** [bronepehota.onrender.com](https://bronepehota.onrender.com/)

## О игре

«Бронепехота» — это настольная варгейма с миниатюрами, где игроки управляют армиями трёх фракций в futuristic setting. Каждая армия состоит из отрядов пехоты и боевых машин, имеющих уникальные характеристики и способности.

### Фракции

- **Полярис** — высокотехнологичная армия с передовым вооружением
- **Протекторат** — мощная и хорошо защищенная фракция
- **Наёмники** — универсальные бойцы с гибкими возможностями

## Возможности приложения

### Конструктор армии

* Фильтрация отрядов по фракции, типу и стоимости
* Поиск по названию
* Добавление отрядов и машин в армию
* Контроль балла очков
* Экспорт и импорт армии в формате JSON

### Игровая сессия

* Управление состоянием армии во время боя
* Отслеживание прочности техники, боезапаса и потерь среди солдат
* Учёт использованных действий каждым отрядом

### Помощник атаки

* Калькулятор попаданий с учётом дистанции
* Калькулятор урона по бронированию цели
* Анимированная бросок кубиков (D6, D12, D20)
* Расчёт ближнего боя

## Быстрый старт

1. Откройте [bronepehota.onrender.com](https://bronepehota.onrender.com/)
2. Выберите фракцию
3. Нажмите «+» чтобы добавить отряды в вашу армию
4. Переключитесь в режим «В Бой» для управления игровой сессией
5. Используйте вкладку «Атака» для расчёта боя

## Добавление новых юнитов

Для добавления новых отрядов или техники отредактируйте JSON файлы в директории `src/data/{фракция}/`.

### Структура директорий

```
src/data/
├── polaris/          # Поларис
│   ├── squads.json   # Отряды пехоты
│   └── machines.json # Техника
├── protectorate/     # Протекторат
│   ├── squads.json
│   └── machines.json
└── mercenaries/      # Наёмники
    ├── squads.json
    └── machines.json
```

### Пример добавления отряда

Откройте `src/data/polaris/squads.json` и добавьте новый объект:

```json
{
  "id": "polaris_new_squad",
  "name": "Новый отряд",
  "shortName": "Новый",
  "faction": "polaris",
  "cost": 75,
  "image": "/images/squads/polaris_new_squad.jpg",
  "soldiers": [
    {
      "rank": 7,
      "speed": 4,
      "range": "D6",
      "power": "1D6",
      "melee": 0,
      "props": ["Г"],
      "armor": 2
    }
  ]
}
```

### Пример добавления техники

Откройте `src/data/polaris/machines.json` и добавьте новый объект:

```json
{
  "id": "polaris_new_machine",
  "name": "Новая машина",
  "shortName": "Машина",
  "faction": "polaris",
  "cost": 120,
  "rank": 2,
  "fire_rate": 2,
  "ammo_max": 16,
  "durability_max": 12,
  "image": "/images/machines/polaris_new_machine.jpg",
  "speed_sectors": [
    {"min_durability": 7, "max_durability": 12, "speed": 4},
    {"min_durability": 1, "max_durability": 6, "speed": 3}
  ],
  "weapons": [
    {
      "name": "Основное оружие",
      "range": "D12",
      "power": "2D20"
    }
  ]
}
```

### Обязательные поля

| Поле | Описание | Пример |
|------|----------|--------|
| id | Уникальный ID | `polaris_light_assault` |
| name | Полное название | `"Лёгкая штурмовая пехота"` |
| shortName | Краткое название | `"Штурмовики"` |
| faction | Фракция | `"polaris"` |
| cost | Стоимость в очках | `70` |

### Обозначение бросков кубиков

- **Дальность**: `D6`, `D12`, `D20`, `D6+2`, `D12+3`
- **Сила**: `1D6`, `2D12`, `ББ` (рукопашная)
- **Свойства**: `["Г"]` - граната, `["БЫ"]` - медик, `[]` - без свойств

### Секторы скорости

Секторы должны покрывать весь диапазон от 1 до `durability_max` без пробелов.
