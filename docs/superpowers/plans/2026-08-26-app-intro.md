# /app: брифинг-интро + короткий тайтл — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Новичок в `/app` видит брифинг-экран «что будет происходить» (шаг `intro` визарда), тайтл вкладки — «Штаб — Бронепехота».

**Architecture:** `IntroBriefing` — глупый presentational-компонент (`onStart`). `ArmyBuilder` расширяет union шагов значением `'intro'`, ранним `return` рендерит брифинг вместо всего контента; резолвер начального шага — чистая функция `initialSetupStep(saved)`. Ключ `bronepehota_setup_step` сегодня никем не пишется — кнопка «Начать» становится его единственным писателем (= флаг «видел интро»). E2E: общий `dismissIntroIfShown` в `confirmRulesAndSource`.

**Tech Stack:** Next.js 14 (App Router, static export), React 18, Tailwind, Jest+RTL, Playwright (CI-only).

Спецификация: `docs/superpowers/specs/2026-08-26-app-intro-design.md`

```tsx
export type SetupStep = 'intro' | 'rules' | 'source' | 'faction' | 'budget' | 'mission' | 'units' | 'preparation';

/** Шаги визарда без брифинга (intro не персистится). */
const PERSISTED_SETUP_STEPS = ['rules', 'source', 'faction', 'budget', 'mission', 'units', 'preparation'];

/**
 * Начальный шаг визарда: новичок (нет сохранённого шага) видит брифинг-intro.
 * SETUP_STEP пишется только кнопкой «Начать» интро — наличие ключа = «видел».
 */
export function initialSetupStep(saved: string | null): SetupStep {
  if (saved && PERSISTED_SETUP_STEPS.includes(saved)) {
    return saved as SetupStep;
  }
  return 'intro';
}
```
