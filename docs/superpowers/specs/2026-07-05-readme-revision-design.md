   | Где | В README сейчас | По данным JSON |

   «Благодарности», дублирующиеся секции правил, отдельная секция «Технологии»
   (дублирует `DEVELOPMENT.md`).

`DEVELOPMENT.md` и `CONTRIBUTING.md` уже выделены отдельно; `CLAUDE.md` — для
AI-ассистента. README должен стать **лендингом для игроков**, без developer- и
