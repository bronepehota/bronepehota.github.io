# Тест пилота на защищающейся машине (при уроне) — дизайн (#163)

**Дата:** 2026-07-01
**Issue:** [#163 — Тест брони D12 и выживания D6 по ЗАЩИЩАЮЩЕЙСЯ машине при каждом попадании](https://github.com/Luxor/bronepehota/issues/163)
**Тип:** bug (механика)
**Scope:** перенос теста пилота из `executeShot` (атакующий) на карточку машины-цели (авто-срабатывание при уроне).

## Контекст и расследование

Правило v0.3 §6 «Тест брони» + §7: при каждом выстреле, нанёсшем машине ≥1 повреждения,
пилот **защищающейся** машины проходит: (1) **тест брони D12** vs «броня машины» (= текущая
прочность), (2) при провале — **тест выживания D6** vs Бр пилота («6» = крит, гибель всегда).
Раз за выстрел.

**Рабочий процесс игрока** (уточнено в диалоге): каждый ведёт свою сессию; когда по **твоей**
машине нанесли урон — **ты** снижаешь её прочность в приложении (`useMachineStats.updateDurability`).
Тест должен срабатывать в этот момент на **самой машине**, по её собственным данным.

## Корневая причина (текущее состояние — два дефекта)

1. **`useCombatFlow.executeShot` (~330–365)**: тест пилота есть, но внутри разрешения выстрела
   и тестирует **атакующего** (`isMachine(state.unit)`): «броня» = прочность атакующего,
   «пилот» = пилот атакующего. Бессмысленно (это в тебя не попали). При стрельбе пехоты по
   машине — не идёт вовсе.
2. **Карточка машины**: тест пилота уже есть (`handlePilotSurvivalTest` → `usePilotTestFlow`),
   с **правильными данными** (`machineArmor = currentDurability`, `pilotArmor = pilotInfo.pilotArmor`),
   но только **ручной** (кнопка). Должен **авто-срабатывать при снижении прочности**.

Данные пилота (currentDurability, pilotInfo.pilotArmor) **уже на машине** — ручных полей не нужно.
(Предыдущий вариант «ручной ввод Бр пилота» был ошибочным — защитник отслеживается.)

## Решение

1. **Удалить** тест пилота из `executeShot` (блок `if (isMachine(state.unit) && damageResult.damage > 0) { … }`).
   Его никто не потребляет (`CombatResults` не отображает pilotDied/armorTestRoll оттуда) — чистое удаление.
2. **Полноширинная alert-полоса «Тест пилота»** (заменяющая мелкий угловой череп):
   - `UnitCard`: `pilotTestUrgent` state (false) + `prevDurabilityRef` (текущая прочность).
   - `useEffect` на `unit.currentDurability` (только машины): при **снижении** → `setPilotTestUrgent(true)`.
     (mount/загрузка не триггерят — `prevDurabilityRef` инициализирован текущей; рост/ремонт не триггерит.)
   - Проп `pilotTestUrgent` → `MachineView` → `TacticalDashboard`: вместо углового Skull-радика —
     **полноширинная полоса** под блоком прочности/кнопок:
     - **idle** (нет урона, нет свежего результата): скрыта.
     - **urgent** (`pilotTestUrgent && pilotInfo?.alive && !isPilotTestRunning`): amber, **пульс**,
       «⚠ ТЕСТ ПИЛОТА · получен урон» — тап запускает тест.
     - **running** (`isPilotTestRunning`): спиннер «ТЕСТ…».
     - **результат** (`survivalTest` без urgent/running): зелёная «✓ ВЫЖИЛ» / красная «✗ ПОГИБ» (тап = повторить).
   - `handlePilotSurvivalTest` (тап) сбрасывает `setPilotTestUrgent(false)` + запускает флоу
     (D12 vs currentDurability → D6 vs pilotInfo.pilotArmor → гибель/выживание).
3. **Гарантия «раз за выстрел»**: игрок применяет урон выстрела (любое число повреждений), затем
   тапает кнопку **один раз** → один тест. 3 повреждения = 1 тап = 1 тест. Нет авто-мульти-срабатывания.

## Non-goals

- Ручные поля ввода данных пилота (не нужны — данные на машине).
- Редизайн карточки машины — отдельная задача (сразу после #163).
- `calculateDamage` / зонный урон / executeShot-логика попадания — не трогаем.

## Краевые случаи

- **Mount с уже повреждённой машиной**: `prevDurabilityRef` = текущая прочность → снижения нет → `pilotTestUrgent` не взводится (исторический урон не подсвечивает кнопку).
- **Ремонт/восстановление** (прочность растёт): не взводит `pilotTestUrgent`.
- **3 повреждения за выстрел**: игрок применяет урон (сколько угодно кликов), кнопка пульсирует → тапает 1 раз → 1 тест. Гарантия «раз за выстрел».
- **Машина без пилота / пилот мёртв**: кнопка не пульсирует (`pilotInfo?.alive` false), `handlePilotSurvivalTest` ранний `return`.
- **Повторный урон после теста**: после тапа `pilotTestUrgent=false`; новое снижение → снова взводится → снова можно тапнуть (новый выстрел = новый тест).

## Тесты

- **E2E** (новый `e2e/defender-pilot-test.spec.ts`): сессия с машиной + живым пилотом;
  снизить прочность → кнопка «Тест пилота» пульсирует/подсвечена → тап → открывается модалка теста (D12/D6).
  Проверить, что `executeShot` (выстрел) больше НЕ тестирует атакующего (старый блок удалён).
- `usePilotTestFlow` логика (D12/D6) уже покрыта — не дублируем.
- Регрессия: shot/melee/граната E2E зелёные (executeShot без теста пилота работает как прежде).

## Критерии приёмки

- [ ] Тест пилота **убран из `executeShot`** (атакующего больше не тестирует).
- [ ] При **снижении прочности машины** (с живым пилотом) авто-открывается тест пилота (D12 vs
      currentDurability → D6 vs pilotInfo.pilotArmor).
- [ ] Не срабатывает на mount/росте/без пилота/во время открытой модалки.
- [ ] Регрессия shot/melee/граната зелёная; `npm run validate` + `npm run test:e2e`.

## Риски

- `useEffect` на `unit.currentDurability` — частый ре-рендер; гард по снижению взводит `pilotTestUrgent` только при уроне.
- «Раз за выстрел» гарантируется ручным тапом (игрок контролирует), а не авто-срабатыванием — нет риска мульти-теста.
