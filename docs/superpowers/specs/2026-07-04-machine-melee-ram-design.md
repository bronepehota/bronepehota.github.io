# ББ + Таран для машин — дизайн (#125)

**Дата:** 2026-07-04
**Issue:** [#125 — ББ + Таран для машин](https://github.com/Luxor/bronepehota/issues/125)
**Тип:** enhancement (боевая механика + UI)
**Scope:** реализовать ближний бой (ББ) машин (обе редакции правил) и Таран по пехоте (community Star System). Только механика боя солдата/машины-атакующего против вручную введённой цели (приложение single-army).

## Контекст и правила (изучены)

**ББ (ближний бой машины)** — обе редакции (Tehnolog `docs/tehnolog/official_rules.md` §8 и Star System `docs/star_system/fan_rules.md` §8), правила идентичны (Таблица 6/7):

- **Сила атаки машины** = `D6 + текущая прочность (Броня) + ΣББ`, где ΣББ — сумма мощностей всех оружий с `range === 'ББ'` (та же формула, что в `MachineView.meleeBonus`).
- **Сила защиты цели** (Таблица 6, по типу):
  - Пехотинец → `D6 + Бр`
  - Боевая машина → `D6 + Броня + ΣББ` (ΣББ цели)
  - Орудие / машина без пилота → только `Броня` (не атакует, без D6)
- **Исход** (Таблица 7): Сила атаки ≤ Сила защиты → «Атака отбита»; > → атакующий выиграл:
  - цель-пехотинец → **Уничтожен**;
  - цель-машина/орудие → **повреждения = (Сила атаки − Сила защиты)**; пилот цели проходит тест выживания (это забота оппонента — приложение только сообщает «N повреждений»).
- **Внезапная атака (тыл)**: атакующий бросает D6 дважды (лучший); у цели-машины **ΣББ не учитывается** в защите (`D6 + Броня`).

**Таран** — только Star System (в правилах Tehnolog его нет; PDF `fan_rules_v0.3.pdf` стр.47):
- Машина переезжает пехотинцев → защитник бросает **D6 на каждого**: `1–4 → убит`, `5–6 → отброшен на шаг (выжил)`. За нескольких пехотинцев — по D6 на каждого.
- «Обычный таран» (машина по машине) правилами не определён — **не реализуем**.

### Текущее состояние кода

- `executeMelee` (`src/hooks/useCombatFlow.ts:464`) разрешает ближний бой, но для атакующей машины берёт `melee=0` (`getCombatStats` возвращает `melee:0` для машин). Защитник — `state.parameters.targetArmor`; есть `isSurpriseAttack` (тыл) и `calculateMelee`/`calculateMeleeWithSurpriseAttack` (`game-logic.ts:189/261`) — основа D6+стат vs D6+стат.
- `ActionSelector` уже разрешает машинам `melee` (`canMelee` = true для машин).
- Карточка машины после #179: оружия дальнего боя (тап = выстрел) + выключенная кнопка «Таран +ΣББ» (placeholder) внизу (`MachineView.tsx`).
- Аналог `meleeBonus`/`hasMelee` уже считается в `MachineView` (ΣББ оружий).

## Решение

### 1. ББ — расширить `executeMelee` для атакующей машины

В `useCombatFlow.ts::executeMelee` для `isMachine(state.unit)`:
- `attackerMelee = currentDurability + ΣББ` (+ модификаторы ближнего боя из `activeModifiers.meleeBonus`).
- Сила защиты цели берётся из расширения `parameters` (см. §3 — тип цели + статы).
- Исход по Таблице 7: «отбита» / «пехотинец уничтожен» / «N повреждений» (для машины-орудия).
- Внезапная атака: атакующий D6×2 (лучший); цель-машина — ΣББ убрана из защиты.

Переиспользует `calculateMelee`/`calculateMeleeWithSurpriseAttack` (D6+стат vs D6+стат); нужна доп. логика исхода Таблицы 7 (бинарный для пехоты vs повреждения для машины-орудия vs «отбита») и расчёт силы цели по типу.

### 2. Таран — новый тип действия `'ram'` (community только)

- Новый `executeRam` в `useCombatFlow.ts`: для `N` пехотинцев бросает D6 на каждого → результат `1–4` = убит, `5–6` = выжил. Возвращает массив `RamInfantryResult[]` + счётчик убитых.
- **Переиспользует паттерн гранаты** (`GrenadeBlastResult[]` / `grenadeBlastChecks` / экран списка попаданий в `CombatResults.tsx:404`): таран по нескольким пехотинцам функционально аналогичен взрыву по зоне — столько же бросков-по-цели. Отличие: у тарана нет ввода брони цели (плоская таблица D6), поэтому броски/all-N-at-once, а не интерактивно по одной (как `checkGrenadeTarget`). Экран результата — список каждого пехотинца (D6 + Убит/Отброшен) и счётчик «X из N убито».
- Гейт: действие доступно только при `rulesVersion === 'community_star_system'`.
- Расход действия: помечает машину (`isMachineMelee`/готов), как выстрел.

### 3. Ввод параметров (`ParameterInputs.tsx`)

- **Ближний бой машины**: добавить **селектор типа цели** (сегмент: Пехотинец / Машина / Орудие-без-пилота) + поля по типу:
  - Пехотинец → `Бр`;
  - Машина → `Броня` + `ΣББ` цели;
  - Орудие → `Броня` (без D6).
  - Существующий тумблер **внезапной атаки**.
- **Таран**: счётчик числа пехотинцев (stepper 1…N).

### 4. Результаты (`CombatResults.tsx`)

- **Ближний бой**: «Сила атаки (D6+X) vs Сила защиты (D6+Y)» + исход («Атака отбита» / «Уничтожен» / «N повреждений»); пометка внезапной атаки.
- **Таран**: на каждого пехотинца — D6 и метку (Убит 1–4 / Отброшен 5–6), итог «X из N убито». Экран переиспользует паттерн `grenade-blast-checks` (список + счётчик).

### 5. UI запуска (`MachineView.tsx`)

Заменить выключенную кнопку «Таран» (placeholder из #179) на **две рабочие кнопки** внизу карточки:
- **«Ближний бой»** — всегда (любая машина: D6+прочность, +ΣББ если есть ББ-оружия); показывает `+ΣББ` при `meleeBonus>0`. Тап → `onMelee()` → `startCombat(unit, undefined, undefined, 'melee')`.
- **«Таран»** — только при `rulesVersion === 'community_star_system'`. Тап → `onRam()` → `startCombat(unit, undefined, undefined, 'ram')`.
Обе открывают combat-модалку на этапе ПАРАМЕТРЫ (действие предвыбрано). `UnitCard.tsx` прокидывает `rulesVersion` в `MachineView` для гейта Тарана и хендлеры `handleVehicleMelee`/`handleVehicleRam`.

### 6. Типы (`combat-types.ts`)

- Добавить `'ram'` в `CombatActionType`.
- `targetType: 'infantry' | 'machine' | 'artillery'` в параметрах ближнего боя машины.
- `RamInfantryResult` (аналог `GrenadeBlastResult`): `{ index, roll, killed }`; результат тарана — `ramInfantryResults: RamInfantryResult[]` (как `grenadeBlastChecks`). Машина-в-ближнем-бою — исход Таблицы 7 + повреждения.

## Non-goals

- Таран машина-по-машине («обычный таран») — правилами не определён.
- Ближний бой с поддержкой (несколько атакующих на одну цель) — отдельная сложная механика.
- Отслеживание позиции/контакта юнитов — приложение single-army, цель вводится вручную.
- Захват машин/орудий (§9) — другая задача.
- Изменение существующего боя солдат или выстрела.

## Краевые случаи

- Машина без ББ-оружий → «Ближний бой» работает (ΣББ=0); «Таран» доступен (community).
- Машина уничтожена (прочность 0) → обе кнопки неактивны.
- Таран нескольких пехотинцев → D6 на каждого.
- Non-community правила → кнопки «Таран» нет; «Ближний бой» есть.
- Цель-орудие/без пилота → защита только `Броня`, без D6; атакующий кидает D6+прочность+ΣББ vs `Броня`.
- Внезапная атака по машине-цели → её ΣББ исключён из защиты.

## Тесты

- **Unit** (`game-logic`): формула силы машины (прочность+ΣББ, +модификаторы); Таблица 7 (пехота уничтожена / машина=N повреждений / отбита); внезапная (ΣББ цели исключён, D6×2 у атакующего); таран (1–4 убит / 5–6 выжил, N пехотинцев).
- **E2E**: машина → «Ближний бой» → ввод цели → результат; community → «Таран» → N пехотинцев → результат. Регрессия shot/граната/melee-солдат зелёная.

## Критерии приёмки

- [ ] «Ближний бой» машины: Сила = D6+прочность+ΣББ; цель по типу (пехота/машина/орудие) — корректная Сила защиты; исход Таблицы 7 (отбита / уничтожен / N повреждений).
- [ ] Внезапная атака: D6×2 у атакующего; ΣББ цели-машины исключён из защиты.
- [ ] «Таран» (community только): D6 на каждого пехотинца, 1–4 убит / 5–6 выжил.
- [ ] Обе кнопки внизу карточки вместо placeholder; «Таран» только для community; обе расходы действие машины.
- [ ] Non-community: «Таран» скрыт; «Ближний бой» работает.
- [ ] `npm run validate` + `npm run test:e2e` зелёные.

## Риски

- Расширение `executeMelee` веткой машины не должно сломать бой солдат (солдат использует `soldier.melee`; машина — прочность+ΣББ) — разделить по `isMachine`.
- Добавление типа цели в `parameters` — не сломать существующий ввод `targetArmor` для выстрела/солдатского melee.
- Таран как новый `CombatActionType` — убедиться, что `executeAction`/`CombatResults`/`ParameterInputs` обрабатывают `'ram'` везде (иначе затык в модалке).
