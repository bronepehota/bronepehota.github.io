# Корзина юнитов в энциклопедии (волна 4)

Дата: 2026-08-27 (переработана из «умного добавления» по решению владельца:
модель = корзина, БЕЗ ограничений на состав)
Статус: утверждён; очередь — после волны 3 (песочница), тот же PR #226.

## Модель

Э-commerce-корзина: гуляешь по энциклопедии → складываешь отряды/машины →
когда готов, «СОБРАТЬ АРМИЮ» переносит содержимое в визард.

**Никаких ограничений на состав**: любые фракции в любой смеси, лимитов
стоимости нет, дубликаты разрешены (2× один отряд = две строки/кол-во).

## Решение

### 1. Хранение

`bronepehota_cart` (localStorage): `{ items: Array<{ unitId: string; sourceId: SourceID; qty: number }> }`.
Хелперы в новом `src/lib/cart.ts` (чистые, тестируемые): `loadCart()`,
`addToCart(cart, unitId, sourceId)`, `removeFromCart`, `setQty`, `cartTotal`
(стоимость через `getSourceUnitCost`), `clearCart`.

### 2. Кнопка «В КОРЗИНУ +» на странице юнита

В панели «// В БОЙ» (отряды и машины): secondary-кнопка
`data-testid="unit-cart-add"` «В КОРЗИНУ +»; после клика — бейдж
«В корзине ×N». Событие `cart_add {unit}`.

### 3. Корзина в шапке энциклопедии

Иконка-кнопка с бейджем-счётчиком (`cart-button`, count = Σ qty; на 0 — не
активна/приглушена) в шапке EncyclopediaPage (рядом с «Хроники»). Клик —
bottom-sheet корзины (паттерн UnitCombatSandbox):

- строки: имя юнита ×qty, стоимость, «−»/«+» (qty), «удалить»;
- итог: стоимость и количество;
- **«СОБРАТЬ АРМИЮ →»** (`cart-launch-button`);
- «Очистить».

### 4. «СОБРАТЬ АРМИЮ» — перенос в визард

Клик: юниты корзины разрешаются в instances (логика добавления как в
`UnitSelector` билдера — переиспользовать/вынести в утилиту), пишутся в
`bronepehota_army.units` (+totalCost), корзина очищается, переход `/app`.
Визард идёт как обычно (правила → источник → фракция → бюджет) — юниты уже
ждут на шаге построителя. Фракцию НЕ предвыбираем (никаких ограничений —
пользователь волен выбрать любую; юниты в армии отображаются независимо).
Армия в бою (`isInBattle`) → подтверждение «Завершить текущий бой и начать
новую армию с корзиной?» (перезапись).
Событие `cart_launch {units, cost}`; переход = `battle_entry {from: 'encyclopedia_cart'}`.

## Аналитика / доки

`cart_add`, `cart_launch` — CLAUDE.md + issue #225 (таблица); `battle_entry`
+значение `encyclopedia_cart`.

## Тестирование

| Что | Тип |
|---|---|
| `cart.ts`: add/remove/qty/total/clear, дубликаты, persistence-конверт | Unit |
| Панель юнита: кнопка, бейдж ×N, `cart_add` | Unit |
| Шапка: счётчик = Σ qty, кнопка disabled при 0 | Unit |
| Панель корзины: строки, итог, «СОБРАТЬ АРМИЮ» → армия содержит юниты, корзина пуста | Unit |
| E2E: юнит → в корзину ×2 → корзина → собрать → `/app` визард → на шаге построителя 2 юнита | E2E |

## Out of scope

- Ограничения состава/бюджета, фракционные проверки — принципиально нет.
- Песочница машин, гранаты (волна 3 как есть).
