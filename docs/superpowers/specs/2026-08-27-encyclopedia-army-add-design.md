# Ускоренный набор армии из энциклопедии

Дата: 2026-08-27
Статус: утверждён владельцем («умное добавление»); очередь — после волны 3
(песочница), тот же PR #226.
Было out-of-scope «подходом C» спеки discoverability — владелец снял запрет.

## Решение

### Панель «// В БОЙ» на странице юнита (отряды И машины)

Кнопка **«ДОБАВИТЬ В АРМИЮ»** (primary, рядом с «ПРОВЕРИТЬ БОЕМ» для отрядов;
для машин — вместо песочницы):

**Умное добавление** (чистая функция `addToArmy(army, unit) → AddResult`,
`src/lib/army-quick-add.ts`, юнит-тестируемая):

| Состояние армии | Поведение |
|---|---|
| Нет/пустая (`units.length === 0`, не в бою) | Создать армию: `faction = юнита`, `sourceId = источник активного стата юнита`, `units = [instance]`, `totalCost = cost`, `currentStep='unit-select'`; `setup_step='units'` |
| Строится, фракция совместима (своя или союзная — `getAlliedFactions`) | Добавить instance (нумерация как в билдере — переиспользовать утилиту), `totalCost += cost` |
| Строится, фракция НЕсовместима | Вернуть `faction-conflict` → UI предлагает «Начать новую армию с этим отрядом?» (второй клик = перезапись, `mode: 'replace'`) |
| Бой идёт (`isInBattle`) | Вернуть `battle-active` → инлайн-подсказка «Бой идёт — завершите его прежде менять армию», ничего не пишем |

Instance создаётся той же логикой, что в `UnitSelector` билдера (найти и
переиспользовать; при расхождении — вынести в общую утилиту).

### UX после добавления

Инлайн-бейдж в панели: «Добавлено: {name} (+{cost})» + ссылка **«К ШТАБУ →»**
(`/app`; `battle_entry {from: 'encyclopedia_unit'}`). Армия уже в билдере на
шаге юнитов — «УСКОРИТЬ ПЕРЕХОД В БОЙ»: в штабе сразу доступен «В БОЙ».

### Аналитика

- `trackEvent('army_add_direct', { unit, mode: 'create' | 'append' | 'replace' })`.
- CLAUDE.md + issue #225 (таблица событий).

### Взаимодействие с волной 3

Панель после обеих волн (squad): «ВЗЯТЬ ОТРЯД В БОЙ» (deep-link) остаётся
вторичной ссылкой; primary = «ДОБАВИТЬ В АРМИЮ», secondary = «ПРОВЕРИТЬ БОЕМ».
Машины: «ВЗЯТЬ В БОЙ» + «ДОБАВИТЬ В АРМИЮ».

## Тестирование

| Что | Тип |
|---|---|
| `addToArmy`: 4 состояния + совместимость фракций + стоимость/нумерация | Unit |
| Панель: кнопки по типам юнита, бейдж «Добавлено», конфликт-флоу, battle-active блок | Unit |
| Страница юнита → добавить → /app армия содержит отряд (e2e, конверт localStorage) | E2E |

## Out of scope

- Песочница машин, гранаты (волна 3 остаётся как есть).
- Бюджетные проверки при добавлении (превышение лимита не блокируем — билдер сам подсветит).
- Массовое добавление/«собрать армию фракции».
