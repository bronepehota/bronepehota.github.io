# Лендинг: один смысловой экран + витрина фракций (вариант B)

Дата: 2026-08-27
Статус: утверждён владельцем (вариант B из трёх предложенных)
Ветка: `feat/battle-discoverability` (PR #226)

## Контекст

После выноса навигации в модульную строку первого экрана (wave 1) низ лендинга
стал набором повторов: FinalCTA «НАЧАТЬ БОЙ» дублирует hero-модуль ШТАБ,
«Помочь проекту» (GitHub/VK/Калькулятор) дублирует футер и hero-модули.
Владелец: «не вижу смысла в скролировании, там дублирование»; низ не читают.

## Решение (B)

Структура лендинга после правки:

```
100dvh: HeroSection (модульная строка) + Footer
FactionsSection            ← единственный блок ниже
PWAInstallHint
```

1. `src/app/page.tsx`: удалить `LoreSection`, дисклеймер-параграф, `FinalCTA`,
   секцию «ПОМОЧЬ ПРОЕКТУ»; убрать неиспользуемые импорты (`Link`, `LoreSection`,
   `FinalCTA`).
2. Удалить файлы `src/components/landing/FinalCTA.tsx` и
   `src/components/landing/LoreSection.tsx` (других ссылок нет).
3. `Footer.tsx`: добавить компактную строку-дисклеймер между рядом ссылок и
   индикатором «ЛИСТАЙТЕ»: «Официальный лор «Технолог» + фанатские материалы
   сообществ. Неточность? «Дополнить» на странице отряда.» (9–10px, slate-600).
4. E2E `landing.spec.ts`: в тесте «should load landing page successfully»
   убрать ассерт `final-cta-button` (кнопки больше нет). Больше `final-cta`
   в e2e не используется (проверить grep'ом).
5. SEO не затрагивается: hero, JSON-LD, sitemap, og-image (скрин hero) — без
   изменений; ключевые слова фракций остаются в FactionsSection.

## Out of scope

- Изменения hero/модульной строки, Footer-ссылок, PWAInstallHint.
- A/B-тесты длины лендинга.
