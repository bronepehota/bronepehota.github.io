# Переработка лора отрядов в энциклопедии + чистка артефактов техники

**Дата:** 2026-06-16
**Автор:** brainstorming-сессия
**Статус:** одобрен пользователем

## Контекст и проблема

Лор отрядов (пехоты) в `src/data/encyclopedia/units/*/squads.json` был сгенерирован **без учёта вселенной** Robogear/Бронепехоты. Конкретные проблемы:

- **Выдуманная хронология**, противоречащая канону: «Эпоха Consolidation/Expansion/Stabilization/Foundation», годы 3275–4451, причём битвы датированы *раньше* основания Империи (4451).
- **Полностью выдуманные** сражения, традиции, производители, локации.
- **Мусор генерации**: китайские символы (支援, 半径, 存储, 最后的…), английский бэкслеш («decent», «allies», «devastating»), битые слова.

Канон вселенной (источник — `robogear.ru/skelet/2/index_2.php`): из 24 развитых миров в ~40 веке сложился Торговый Протекторат; в **4451 году** Империя Полярис (потомки старого Разведывательного Корпуса) внезапно атаковала планеты Протектората.

Лор **техники** каноничен и устраивает пользователя — требуется лишь точечная чистка артефактов.

## Цель

1. Переписать лор **31 отряда** (polaris 9, protectorate 14, mercenaries 8), сделав его канон-обоснованным.
2. Добавить каждому отряду `shortDescription` — суммарную строку (как у техники).
3. Точечно подчистить артефакты в лоре техники (только снятие мусора, без переписывания канон-лора).

## Скоуп

**Включено:**
- `src/data/encyclopedia/units/{polaris,protectorate,mercenaries}/squads.json` — 31 отряд.
- `src/data/encyclopedia/units/polaris/machines.json` — 5 точечных правок артефактов.

**Исключено:**
- Любое переписывание канон-лора техники (только снятие артефактов).
- Отряды источника tehnolog (их нет в энциклопедии — только в `src/data/sources/`).
- Отложенная задача `unit.description` в source-данных (отдельный таск в памяти).
- Кодовая правка суммарной строки — `UnitDetailSheet.loreLine()` (строка 30) уже предпочитает `shortDescription`, код менять не нужно.

## Изменение модели данных (объект `encyclopedia` у отряда)

| Поле | Решение | Где рендерится |
|---|---|---|
| `class` | **оставить** | detail page, `UnitDetailsModal`, `UnitHeader` |
| `lore` | **переписать** (1–3 предложения, по канону) | `UnitLore`, `UnitDetailsModal` |
| `history` | **переписать** (создание/происхождение, без фейковых эпох/дат) | `UnitLore`, `UnitDetailsModal` |
| `tactics` | **почистить** (оставить игромех. советы по реальным статам; убрать мусор) | `UnitTactics`, `EncyclopediaModal`, `UnitDetailsModal` |
| `shortDescription` | **добавить** (1 строка, ~до 100 символов) | `UnitDetailSheet` — попап в билдере армии |
| `traditions` | ❌ удалить | — |
| `keyBattles[]` | ❌ удалить | — |
| `locations[]` | ❌ удалить | — |
| `manufacturer` | ❌ удалить (мёртвое поле — нигде не рендерится для отрядов) | — |

Типы менять не нужно: `EncyclopediaLore` (`src/lib/encyclopedia-registry.ts`) уже содержит `shortDescription?: string` и `[key: string]: any`.

## Источник канона

1. **`/home/atuzov/Downloads/EmpPolaris.docx`** (+ `.pdf`) и **`Protektorat.pdf`** — официальный лор фракций. Извлечение: docx → `python3 -c "import zipfile; zipfile.ZipFile('...docx').read('word/document.xml')"`; pdf → `pdftotext -layout`.
2. **`robogear.ru`** — вселенная и планеты (Велиан и т.п.).
3. **Форум Технолога** (`newforum.tehnolog.ru/…showforum=66`) — вторично.

Где книги/канон молчат о конкретном отряде — короткое описание по **роли + канону фракции** (авторизовано пользователем). У наёмников книги нет — grounding по фракционному описанию (пираты, Внешнее Кольцо, мародёры) + роль.

## Правила контента

- **Тон** — как у техники: сухой, роль-ориентированный, в рамках вселенной.
- **Никаких** выдуманных дат/битв/мест/традиций, противоречащих канону. Если дата нужна — только канонические (4451 и т.п.).
- **Никакого мусора**: CJK-символы, английский, битые слова.
- `shortDescription` — одна строка, суть отряда.

Пример (`polaris_lineynaya_klon_pehota`):
```
lore:            «Основная клон-пехота Империи Полярис. Клоны выращиваются на заводах-инкубаторах, программируются на безусловную преданность и формируют костяк имперских экспедиционных сил.»
history:         «Появилась после перехода Империи от призывных армий к серийному клонированию; стандарт для всех секторов Империи Полярис.»
tactics:         «Дешёвый отряд для заполнения рядов: захват точек, удержание позиций, стрелковая линия. 5 бойцов с D12 бьют на средней дистанции, слабы в ближнем бою.»
shortDescription:«Основная клон-пехота Империи: дешёвая масса для удержания позиций и стрелковой линии.»
```

## Тестирование и влияние

- Юнит-тесты работают на синтетических данных; E2E (`encyclopedia.spec.ts`) **не** ассертит текст лора → изменения безопасны.
- `UnitLore`/`UnitDetailsModal` условно рендерят поля → удалённые секции (`traditions`/`keyBattles`/`locations`) просто исчезнут.
- `hasLoreExpansion`/`formatBattleYear` (`src/lib/lore-utils.ts`) — мёртвый код (не используется); трогать не обязательно.
- **Финальная проверка**: `npm run type-check && npm run lint && npm run test && npm run test:e2e`.
- Желательно: после правок прогнать повторный скан на CJK/английский по всем encyclopedia-JSON как регрессию (0 попаданий вне `sourceUrl`).
