# Дизайн: Стандартизация изображений солдат

**Дата:** 2026-02-14
**Статус:** Утверждён

## Проблема

В директории `public/images/squads/` содержатся 184 изображения миниатюр солдат для настольной варгейма. Изображения не стандартизированы:
- Размеры: от 1280×1160 до 4032×3024 пикселей
- Фигурки смещены относительно центра
- Большие неравномерные отступы (15-33% с каждой стороны)

Это приводит к нестабильному отображению в UI приложения.

## Решение

Автоматическая обработка всех изображений с приведением к единому формату.

## Параметры стандартизации

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| Целевой размер | 300×400 px | Оптимален для мобильных карточек, быстрая загрузка |
| Отступы | 5% от контента | Минимальные, максимум полезной площади |
| Формат | PNG | Без потерь качества |
| Фон | Белый (#FFFFFF) | Сохраняется как в оригинале |

## Архитектура

```
tools/
└── standardize_images.py    # Скрипт обработки

public/images/
├── squads/                  # Обработанные изображения
├── squads_backup/           # Резервные копии оригиналов
└── standardization_report.html  # Отчёт для валидации
```

## Алгоритм обработки

```
Для каждого изображения в squads/:
1. Загрузить изображение через PIL
2. Создать резервную копию в squads_backup/ (если ещё нет)
3. Конвертировать в grayscale для анализа границ
4. Найти bounding box: все пиксели где value < 250 (не белые)
5. Расширить bounding box на 5% с каждой стороны
6. Обрезать изображение по bounding box
7. Создать холст 300×400 белого цвета
8. Масштабировать обрезанное изображение, сохранить пропорции
9. Разместить по центру холста
10. Сохранить как PNG с оптимизацией
11. Записать метаданные для отчёта
```

## HTML-отчёт

Файл `standardization_report.html` содержит:

- Общую статистику (количество, средний размер до/после)
- Сетку карточек для каждого изображения:
  - Миниатюра "До" (максимум 150px)
  - Миниатюра "После" (максимум 150px)
  - Имя файла и путь
  - Размеры до обработки
  - Размеры после обработки
  - Статус (OK / предупреждение)

## Обработка ошибок

- Пропуск нечитаемых файлов с записью в лог
- Предупреждение об изображениях с очень маленьким контентом
- Сохранение списка проблемных файлов в отчёт

## Безопасность данных

- Резервные копии создаются перед любой обработкой
- Повторный запуск скрипта проверяет наличие бэкапа
- Оригиналы можно восстановить из `squads_backup/`

## Зависимости

- Python 3.x
- Pillow (PIL) — библиотека обработки изображений

## Критерии успеха

1. Все 184 изображения обработаны
2. Все файлы имеют размер 300×400 px
3. Фигурки отцентрированы с 5% отступами
4. HTML-отчёт позволяет визуально проверить результат
5. Оригиналы сохранены в backup
