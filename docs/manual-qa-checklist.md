# Manual QA Checklist - Combat Card Improvements

## Тестирование долгого нажатия (Long-Press)

### ГОТОВ button (завершение хода)

**Сценарий для проверки:**

1. **Активация (короткий клик)**:
   - [ ] Найти отряд, открыть карточку бойца
   - [ ] Убедиться что боец НЕ завершён (серая кнопка ГОТОВ)
   - [ ] Короткий клик по ГОТОВ
   - [ ] Проверить: боец стал завершённым (зелёная кнопка)
   - [ ] Проверить: прогресс-бар НЕ появился

2. **Отмена (долгое нажатие)**:
   - [ ] Найти бойца, который уже завершён (зелёная кнопка ГОТОВ)
   - [ ] Долгое нажатие на кнопку ГОТОВ (~700мс)
   - [ ] Проверить: появился прогресс-бар внизу карточки
   - [ ] Проверить: после ~700мс боец вернулся в активное состояние
   - [ ] Проверить: все действия (походил, выстрелил) сброшены

### УБИТЬ button

**Сценарии для проверки:**

1. **Активация (короткий клик)**:
   - [ ] Найти живого бойца
   - [ ] Короткий клик по УБИТЬ
   - [ ] Проверить: боец стал мёртвым (красная кнопка, череп)
   - [ ] Проверить: прогресс-бар НЕ появился

2. **Воскрешение (долгое нажатие)**:
   - [ ] Найти мёртвого бойца (красная кнопка УБИТЬ)
   - [ ] Долгое нажатие на кнопку УБИТЬ (~700мс)
   - [ ] Проверить: появился прогресс-бар внизу карточки
   - [ ] Проверить: после ~700мс боец вернулся в живое состояние

## Визуальные элементы

### Цветовая полоса статуса (StatusStripe)

- [ ] **Активный боец**: полоска не видна или почти не видна
- [ ] **Завершённый боец**: зелёная полоса слева (emerald-500→600)
- [ ] **Мёртвый боец**: красная полоса слева (red-600→700)
- [ ] **В панике**: оранжевая полоса слева (orange-500→amber-500)

### Мягкое затемнение

- [ ] Завершённый боец: `opacity-90` (читается, но затемнён)
- [ ] НЕ используется `grayscale` фильтр
- [ ] Карточка остаётся разборчивой

### Кнопки

- [ ] **ГОТОВ (завершён)**: gradient от emerald-600 до emerald-800
- [ ] **ГОТОВ (завершён)**: свечение shadow-[0_0_15px_rgba(16,185,129,0.5)]
- [ ] **УБИТЬ (мёртв)**: gradient от red-700 до red-900
- [ ] **УБИТЬ (мёртв)**: свечение shadow-[0_0_15px_rgba(220,38,38,0.5)]

### Броня

- [ ] Броня выделена жёлтым цветом (text-yellow-400)
- [ ] Размер такой же как у других статов
- [ ] НЕ перенабряжена (нет рамки, фона, свечения)

### Прогресс-бар

- [ ] Появляется ТОЛЬКО при долгом нажатии на кнопках ГОТОВ/УБИТЬ
- [ ] Высота: 0.5px (очень тонкий)
- [ ] Расположен: внизу карточки солдата
- [ ] Цвет: зелёный (emerald-500→600)
- [] Заполняется за ~700мс (с задержкой 100мс перед появлением)

## Угловые случаи

### Многократные нажатия

- [ ] Несколько коротких кликов на ГОТОВ → каждый клик переключает состояние
- [ ] Несколько коротких кликов на УБИТЬ → каждый клик переключает состояние
- [ ] Долгое нажатие → отмена работает корректно

### Быстрое отпускание

- [ ] Начать долгое нажатие, отпустить через 200мс → активация, НЕ отмена
- [ ] Прогресс-бар НЕ должен появиться (отпустили раньше 100мс)

### Паника

- [ ] Боец в панике → кнопка ГОТОВ отключена
- [ ] Долгое нажатие на паническом бойце не должно работать

## После отработки

### Сохранение состояния

- [ ] Локальное хранилище обновляется корректно
- [ ] После F5 состояние сохраняется
- [ ] Можно отменить действия и переделать

### Accessibility

- [ ] Tab переключается между кнопками корректно
- ] ] Focus виден на кнопках
- [ ] aria-label описывает текущее состояние
