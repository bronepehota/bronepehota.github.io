# Архив исходников лора (lore-sources)

Дословные исходники лора вселенной «Бронепехота»/«СтарСис»/«Робогир» в
Markdown-формате — **для потомков и для разработки**. Каждая единица архива —
конвертация оригинального файла (PDF/DOC/DOCX/веб-страница) с шапкой-фронтматтером:
источник, оригинал, правообладатель, дата обработки.

> **Эти файлы — архив, а не контент приложения.** В продакшен-сборку сайта они
> **не входят** (всё под `docs/` вне `src/`). В энциклопедию лор попадает
> адаптацией/пересказом через `src/**` — см. реестр
> [`docs/ENCYCLOPEDIA_LORE_SOURCES.md`](../ENCYCLOPEDIA_LORE_SOURCES.md).

## Конвертация

- PDF → `pdftotext -raw` (кривая кириллица InDesign → декод `latin-1→CP1251`);
- DOC/DOCX → `soffice --headless --convert-to txt:Text`;
- веб-страницы robogear.ru → `curl` + декод CP1251→UTF-8 + чистка вёрстки 2008 г.

Текст сохраняется **дословно** (архив, не адаптация): опечатки оригинала,
артефакты конвертации и вёрстки не правятся, особенности отмечаются в шапке.
