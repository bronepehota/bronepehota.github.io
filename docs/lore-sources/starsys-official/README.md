# starsys-official/ — официальная PDF-библиотека «Варгеймы „СтарСис"»

Дословные конверты документов из официальной библиотеки сообщества
**«Варгеймы „СтарСис"»** (ООО «Технолог», `vk.ru/docs-32426380`) — 25 PDF,
залиты в VK 2021-09-03/04/07 (точная дата каждого дока анонимно не видна,
в шапках конвертов стоит `2021-09-04`).

Библиотека не обрабатывалась до 2026-09 (ревизия источников): в неё нашёлся
«разыскиваемый» долг «Летопись Звёздного Бытия», события-сценарии (Регана,
Рун, Гронт, Битва на Песке), печатный каталог бронетехники и миссии
первой редакции Robogear.

## Примечания

- **Дубль «Летописи».** `letopis-zvezdnogo-bytiya.md` (18 стр., 2002) и
  [`star-heroes/Летопись-Звёздные-герои.md`](../star-heroes/Летопись-Звёздные-герои.md)
  (65 стр., 2005) — один и тот же труд «История человечества (краткое изложение)»:
  тексты совпадают дословно, но 65-страничное издание заметно длиннее
  (~30 тыс. знаков против ~138 тыс. в нормализованном виде). Для импорта в
  приложение считать одним источником (см. п. 1 каталога
  `letopis-zvezdnye-geroi`); VK-версия ценна как первоиздание 2002 г.
- **«Схватка на Гронте» и «Вторжение на Рун»** — те самые события, что были
  транскрибированы по фотографиям книги в [`starsys-2001/`](../starsys-2001/);
  PDF здесь — более качественный первоисточник, если понадобится сверка.
- **Каталог** хранит текст в cp1251: `pdftotext` отдаёт латиницу-моджибейк,
  разворот — `bytes.encode('cp1252').decode('cp1251')` (тире U+2013 при этом
  сохраняются; рецепт `latin-1` из конспекта заменял бы их на `?`).
- **PDF-оригиналы в репозиторий не кладутся** (только текстовые конверты);
  копии всех 25 PDF живут в VK (`vk.ru/docs-32426380`), локальная рабочая
  копия — `/tmp/starsys_docs/` (нестабильно, при необходимости скачать заново:
  прямые ссылки с хешем живут долго, список — в журнале сессии 2026-09-12).

## Конвертация

- `pdftotext -raw` из PDF библиотеки; сканы без текстового слоя — только
  постраничным vision-OCR (здесь не делалось).
- Текст сохраняется **дословно**: опечатки, склеенные переносы
  («единственнымпутемспасениядлячеловечества»), оборванные на переносе слова
  («"Роботехп») и подписи легенд схем не правятся — см. шапку каждого конверта.
