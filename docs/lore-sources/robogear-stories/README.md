# Дословные тексты рассказов robogear.ru

Дословные тексты рассказов игроков с robogear.ru — справочный архив для
разработчиков, в продакшен-сборку не входит (`docs/` не импортируется приложением).

- **Откуда**: `robogear.ru/skelet/6/story_*.php` (Клуб Robogear, 2008; загрузка и
  чистка вёрстки — `tools/robogear_story_fetch.py` + ручная вычитка).
- **Почему здесь**: решение владельца 2026-08-28 — творчество игроков публикуется
  в энциклопедии только как лор-сведения (события, техника, формирования, мир),
  а не как художественные тексты; дословные рассказы остаются в этом архиве.
